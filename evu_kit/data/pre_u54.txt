@theory
## A | The computer | Máy tính
*webcam, microphone, printer, screen, keyboard, escape key, spacebar, mouse mat, mouse, CD-ROM, memory stick*. ‖ *webcam, micro, máy in, màn hình, bàn phím, phím Esc, phím cách, tấm lót chuột, chuột, đĩa CD-ROM, USB*.
## B | Using a computer | Dùng máy tính
*switch on; log in/on (opp log out/off) with your username; enter your password; double-click on an icon; open an application; store information; back up files (make a backup); create a document; File menu; copy and paste; save; print out (a hard copy / a printout); the computer crashes; exit*. ‖ *đăng nhập/đăng xuất, tên người dùng, nhập mật khẩu, nhấp đúp, biểu tượng, ứng dụng, lưu trữ, sao lưu, tạo, sao chép, dán, lưu, in ra, bản in, bị treo, thoát*.
## C | FAQs about computers | Câu hỏi thường gặp
*PC* or *laptop*; *hard drive* (*hard disk*); *operating system*; *install software*; *run* applications; *anti-virus software*, a *virus*. ‖ *máy tính cá nhân, máy tính xách tay, ổ cứng, hệ điều hành, phần mềm, chạy, phần mềm diệt virus*.
