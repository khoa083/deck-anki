@title_vi: Cụm từ với set và put
@theory
## A | Phrasal verbs based on set | Cụm động từ với set
*set aside* [reserve; ignore (not think about)], *set off* [begin a journey; cause], *set out* [begin something with a particular aim in mind], *set up* [establish]. ‖ *để dành/gạt sang một bên, khởi hành/gây ra, bắt đầu với mục tiêu, thành lập*.
## B | Phrasal verbs with put | Cụm động từ với put
*put forward* [propose], *put in* [submit; say something; install], *put across* [communicate], *put down* [make someone look small], *put together* [assemble], *put on* [present; pretend to have], *put out* [inconvenience], *put away* [tidy], *put up* [give accommodation to; raise; display], *put off* [postpone; distract], *put up with* [tolerate]. It would not normally be natural to use all of these expressions together. ‖ *đề cử, nộp/xen vào/lắp đặt, truyền đạt, hạ nhục, lắp ráp, trình diễn/giả giọng, làm phiền, cất dọn, cho ở nhờ/tăng/treo, hoãn/làm xao nhãng, chịu đựng*.
## C | Expressions with set and put | Cụm với set và put
*set your heart/sights on, set yourself a target, set/put the world to rights, set fire to, set free, set foot in, set a record, set a good example; put your foot down, put pressure on, put your mind to, put two and two together, put an end/a stop to, put someone’s back up, a put-up job*. ‖ *khao khát, đặt mục tiêu, bàn chuyện thiên hạ, phóng hỏa, trả tự do, đặt chân đến, lập kỷ lục, làm gương; kiên quyết, gây áp lực, dồn tâm trí, suy ra, chấm dứt, làm ai bực, trò dàn dựng*.
