@title_vi: It … (chủ ngữ giả it)
@theory
## A | it for time / day / distance / weather | it cho thời gian / ngày / khoảng cách / thời tiết
We use **it** for time / day / distance / weather: ‖ Dùng **it** cho thời gian / ngày / khoảng cách / thời tiết:
*time*: ‖ *thời gian*:
- What time is **it**? / **It**’s half past ten. / **It**’s late. / **It**’s time to go home. ‖ Mấy giờ **rồi**? / Mười giờ rưỡi **rồi**. / Muộn **rồi**. / **Đến** giờ về nhà **rồi**.
*day*: ‖ *ngày*:
- What day is **it**? / **It**’s Thursday. / **It**’s 16 March. / **It** was my birthday yesterday. ‖ Hôm nay là thứ mấy? / **Hôm nay** là thứ Năm. / **Hôm nay** là 16 tháng Ba. / Hôm qua **là** sinh nhật tôi.
*distance*: ‖ *khoảng cách*:
- **It**’s three kilometres from our house to the city centre. ‖ Từ nhà chúng tôi đến trung tâm thành phố **là** ba ki-lô-mét.
- How far is **it** from New York to Los Angeles? ‖ Từ New York đến Los Angeles **bao xa**?
- **It**’s a long way from here to the station. ‖ Từ đây đến nhà ga **xa lắm**.
- We can walk home. **It** isn’t far. ‖ Chúng ta có thể đi bộ về nhà. **Không** xa đâu.
We use **far** in questions (**is it far?**) and negatives (**it isn’t far**). In positive sentences, we use **a long way** (**it’s a long way**). ‖ Dùng **far** trong câu hỏi (**is it far?**) và câu phủ định (**it isn’t far**). Trong câu khẳng định, dùng **a long way** (**it’s a long way**).
*weather*: ‖ *thời tiết*:
- **It**’s raining. **It** isn’t raining. Is **it** snowing? ‖ Trời đang mưa. Trời không mưa. Trời có đang có tuyết không?
- **It** rains a lot here. **It** didn’t rain yesterday. Does **it** snow very often? ‖ Ở đây trời mưa nhiều. Hôm qua trời không mưa. Có hay có tuyết không?
- **It**’s warm / hot / cold / fine / cloudy / windy / sunny / foggy / dark etc. ‖ Trời ấm / nóng / lạnh / đẹp / nhiều mây / nhiều gió / nắng / có sương mù / tối v.v.
- **It**’s a nice day today. ‖ Hôm nay **trời** đẹp.
Compare **it** and **there**: ‖ So sánh **it** và **there**:
- **It rains** a lot in winter. / **There is a lot of rain** in winter. ‖ Mùa đông **trời mưa** nhiều. / Mùa đông **có nhiều mưa**.
- **It** was very **windy**. / **There** was **a strong wind** yesterday. ‖ **Trời** rất **nhiều gió**. / Hôm qua **có gió mạnh**.
## B | It’s nice to … etc. | It’s nice to … v.v.
**It’s** easy / difficult / impossible / dangerous / safe / expensive / interesting / nice / wonderful / terrible etc. **to** … ‖ **It’s** easy / difficult / impossible / dangerous / safe / expensive / interesting / nice / wonderful / terrible v.v. **to** … (làm việc gì thì dễ / khó / …)
- **It**’s nice **to see you again**. ‖ **Rất vui được gặp lại bạn**.
- **It**’s impossible **to understand her**. ‖ **Không thể nào hiểu nổi cô ấy**.
- **It** wasn’t easy **to find your house**. ‖ **Tìm nhà bạn không dễ chút nào**.
## C | Don’t forget it | Đừng quên it
- **It**’s raining again. (*not* Is raining again) ‖ **Trời** lại mưa rồi. (*không nói* Is raining again)
- Is **it** true that you’re going away? (*not* Is true that …) ‖ **Có** thật là bạn sắp đi xa không? (*không nói* Is true that …)
@rules
A1: it for time, days and dates (What time is it? It’s Thursday.). ‖ it cho giờ, thứ, ngày (What time is it? It’s Thursday.).
A2: it for distance: How far is it …? / It isn’t far / It’s a long way. ‖ it cho khoảng cách: How far is it …? / It isn’t far / It’s a long way.
A3: it for weather (It’s raining / It’s cold); there + noun (There was a strong wind). ‖ it cho thời tiết (It’s raining / It’s cold); there + danh từ (There was a strong wind).
B: It’s + adjective + to … (It’s nice to see you). ‖ It’s + tính từ + to … (It’s nice to see you).
C: Don’t leave out it: It’s raining (not Is raining). ‖ Không bỏ it: It’s raining (không nói Is raining).
