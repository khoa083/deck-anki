@title_vi: should (nên)
@theory
## A | should + infinitive | should + động từ nguyên mẫu
- You **shouldn’t watch** TV so much. ‖ Bạn **không nên xem** TV nhiều như vậy.
I / we / you / they / he / she / it **should** / **shouldn’t** do / stop / go / watch etc. ‖ I / we / you / they / he / she / it **should** / **shouldn’t** do / stop / go / watch v.v.
## B | You should do something = it is a good thing to do | You should do something = đó là việc nên làm
You **should** do something = it is a good thing to do, it is the right thing to do: ‖ You **should** do something = đó là việc tốt nên làm, việc đúng đắn:
- Tom doesn’t study enough. He **should study** harder. ‖ Tom học chưa đủ. Cậu ấy **nên học** chăm hơn.
- It’s a good film. You **should go** and see it. ‖ Phim hay đấy. Bạn **nên đi** xem.
- When you play tennis, you **should** always **watch** the ball. ‖ Khi chơi quần vợt, bạn **nên** luôn **nhìn** theo bóng.
## C | You shouldn’t do something = it is not a good thing to do | You shouldn’t do something = không nên làm
**shouldn’t** = should not: ‖ **shouldn’t** = should not:
- Tom **shouldn’t go** to bed so late. ‖ Tom **không nên đi** ngủ muộn như vậy.
- You watch TV all the time. You **shouldn’t watch** TV so much. ‖ Bạn xem TV suốt. Bạn **không nên xem** TV nhiều như vậy.
## D | I think … should … / I don’t think … should … / Do you think … should …? | Tôi nghĩ … nên … / Tôi không nghĩ … nên … / Bạn có nghĩ … nên …?
**I think** … **should** … (= I think it is a good idea): ‖ **I think** … **should** … (= tôi nghĩ đó là ý hay):
- **I think** Lisa **should buy** some new clothes. ‖ **Tôi nghĩ** Lisa **nên mua** mấy bộ quần áo mới.
- It’s late. **I think** I **should go** home now. ‖ Muộn rồi. **Tôi nghĩ** tôi **nên về** nhà bây giờ.
- A: Shall I buy this coat? B: Yes, **I think** you **should**. ‖ A: Tôi có nên mua cái áo khoác này không? B: Có, **tôi nghĩ** bạn **nên mua**.
**I don’t think** … **should** … (= I don’t think it is a good idea): ‖ **I don’t think** … **should** … (= tôi không nghĩ đó là ý hay):
- **I don’t think** you **should work** so hard. ‖ **Tôi nghĩ** bạn **không nên làm việc** vất vả như vậy.
- **I don’t think** we **should go** yet. It’s too early. ‖ **Tôi nghĩ** chúng ta **chưa nên đi**. Còn sớm quá.
**Do you think** … **should** … ?: ‖ **Do you think** … **should** … ?:
- **Do you think** I **should buy** this hat? ‖ **Bạn có nghĩ** tôi **nên mua** cái mũ này không?
- What time **do you think** we **should go** home? ‖ **Bạn nghĩ** mấy giờ chúng ta **nên về** nhà?
## E | must is stronger than should | must mạnh hơn should
- It’s a **good** film. You **should** go and see it. ‖ Phim **hay** đấy. Bạn **nên** đi xem.
- It’s a **fantastic** film. You **must** go and see it. ‖ Phim **hay tuyệt**. Bạn **phải** đi xem.
## F | ought to = should | ought to = should
Another way to say **should** is **ought to**: ‖ Một cách nói khác của **should** là **ought to**:
- It’s a good film. You **ought to go** and see it. (= you should go) ‖ Phim hay đấy. Bạn **nên đi** xem. (= you should go)
- I think Lisa **ought to buy** some new clothes. (= Lisa should buy) ‖ Tôi nghĩ Lisa **nên mua** mấy bộ quần áo mới. (= Lisa should buy)
@rules
B: should + infinitive = it is a good / the right thing to do. ‖ should + nguyên mẫu = nên làm (việc tốt, đúng đắn).
C: shouldn’t (should not) + infinitive = it is not a good thing to do. ‖ shouldn’t (should not) + nguyên mẫu = không nên làm.
D: I think … should / I don’t think … should (not I think … shouldn’t) / Do you think … should …? ‖ I think … should / I don’t think … should (phủ định đặt ở think) / Do you think … should …?
E: must is stronger than should. ‖ must mạnh hơn should.
F: ought to = should. ‖ ought to = should (nên).
