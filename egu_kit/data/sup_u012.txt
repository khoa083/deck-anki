@rules
E73: should (be doing) = what is right now; shouldn’t have done = it was wrong (past); mustn’t = it is important not to; doesn’t have to = it isn’t necessary; didn’t need to = it wasn’t necessary (so she didn’t); needn’t have done = she did it, but it wasn’t necessary. ‖ should (be doing) = điều nên làm lúc này; shouldn’t have done = việc đó sai (quá khứ); mustn’t = quan trọng là không được; doesn’t have to = không cần; didn’t need to = không cần (nên đã không làm); needn’t have done = đã làm nhưng không cần thiết.
E74: should / ought to = the right thing to do; should have done = it was right but you didn’t; don’t have to = not necessary; needn’t have done = it was done but unnecessary; must have done = I’m sure it happened; should be = expected to be. ‖ should / ought to = điều đúng nên làm; should have done = lẽ ra nên làm nhưng đã không; don’t have to = không cần; needn’t have done = đã làm nhưng không cần; must have done = chắc chắn đã xảy ra; should be = lẽ ra phải (đang) ở.
E76: must = necessary / important; mustn’t = important not to; needn’t = not necessary; should(n’t) = (not) the right thing to do; should(n’t) have done = past criticism or regret. ‖ must = cần / quan trọng; mustn’t = không được; needn’t = không cần; should(n’t) = (không) nên; should(n’t) have done = phê phán hoặc hối tiếc về quá khứ.
E77: vital → must; not necessary → needn’t; recommended / a good idea → should; not recommended → shouldn’t; forbidden → mustn’t. ‖ bắt buộc → must; không cần → needn’t; khuyến nghị / nên → should; không khuyến nghị → shouldn’t; bị cấm → mustn’t.
E78: shouldn’t have done = it was wrong; should have done = it was right but he didn’t; needn’t have done = he did it but it wasn’t necessary; must have done = I’m sure he did. ‖ shouldn’t have done = lẽ ra không nên làm; should have done = lẽ ra nên làm nhưng đã không; needn’t have done = đã làm nhưng không cần; must have done = chắc chắn đã làm.
E79: ought (not) to + infinitive for present / future; ought (not) to have + past participle for the past. ‖ ought (not) to + động từ nguyên mẫu cho hiện tại / tương lai; ought (not) to have + quá khứ phân từ cho quá khứ.
E80: had better is for a particular situation (not for things in general) and means you could have problems if you don’t; should is also for general advice and expectations. ‖ had better dùng cho một tình huống cụ thể (không dùng cho điều chung chung) và hàm ý sẽ gặp rắc rối nếu không làm; should dùng được cả cho lời khuyên chung và sự kỳ vọng.
E81: have to = necessity (often because of rules or circumstances); don’t have to = not necessary; should = expectation or advice; had better = advice for a particular situation. ‖ have to = sự cần thiết (thường do quy định hoặc hoàn cảnh); don’t have to = không cần; should = kỳ vọng hoặc lời khuyên; had better = lời khuyên cho tình huống cụ thể.
E82: compulsory / essential → have to; advisable → should; not acceptable → shouldn’t; I suggest / a good idea → ’d better; not a good idea → ’d better not; no charge → don’t have to. ‖ bắt buộc / thiết yếu → have to; nên → should; không chấp nhận được → shouldn’t; tôi đề nghị / ý hay → ’d better; không nên → ’d better not; không tính phí → don’t have to.
