@title_vi: one/ones (cái, chiếc – thay cho danh từ)
@theory
## A | one (= a …) | one (= a …)
- These chocolates are good. Would you like **one**? (= Would you like **a chocolate**?) ‖ Sô-cô-la này ngon lắm. Bạn ăn **một viên** không?
**one** = **a / an** … (a chocolate / an apple etc.): ‖ **one** = **a / an** … (a chocolate / an apple v.v.):
- I need **a pen**. Do you have **one**? (**one** = **a pen**) ‖ Tôi cần **một cây bút**. Bạn có **cây nào** không?
- A: Is there **a bank** near here? B: Yes, there’s **one** at the end of this street. (**one** = **a bank**) ‖ A: Gần đây có **ngân hàng** không? B: Có, có **một cái** ở cuối phố này.
## B | one and ones | one và ones
**one** (singular) = hat / car / girl etc.; **ones** (plural) = flowers / cars / girls etc. ‖ **one** (số ít) = hat / car / girl v.v.; **ones** (số nhiều) = flowers / cars / girls v.v.
- **Which one** do you want? **This one**. (Which **one**? = Which **hat**?) ‖ Bạn muốn **cái nào**? **Cái này**. (Which **one**? = cái mũ nào?)
- **Which ones** do you want? **The white ones**. (Which **ones**? = Which **flowers**?) ‖ Bạn muốn **những bông nào**? **Những bông màu trắng**.
**this one / that one**; **these / those** or **these ones / those ones**: ‖ **this one / that one**; **these / those** hoặc **these ones / those ones**:
- Which **car** is yours? **This one** or **that one**? (= this car or that car) ‖ Xe nào là của bạn? **Chiếc này** hay **chiếc kia**?
- Which flowers do you want? **These** or **those**? *or* **These ones** or **those ones**? ‖ Bạn muốn hoa nào? **Những bông này** hay **những bông kia**?
## C | the one … / the ones … | the one … / the ones …
- A: Which **hotel** did you stay at? B: **The one** opposite the station. ‖ A: Bạn ở khách sạn nào? B: **Cái** đối diện nhà ga.
- I found this **key**. Is it **the one** you lost? ‖ Tôi nhặt được chiếc chìa khóa này. Có phải **chiếc** bạn làm mất không?
- A: Which **books** are yours? B: **The ones** on the table. ‖ A: Sách nào của bạn? B: **Mấy cuốn** trên bàn.
- I found these **keys**. Are they **the ones** you lost? ‖ Tôi nhặt được mấy chiếc chìa khóa này. Có phải **những chiếc** bạn làm mất không?
## D | the … one / the … ones; a … one / some … ones | the … one / the … ones; a … one / some … ones
- I don’t like the black **coat**, but I like **the brown one**. ‖ Tôi không thích áo khoác đen, nhưng thích **cái màu nâu**.
- Don’t buy that **camera**. Buy **the other one**. ‖ Đừng mua máy ảnh đó. Mua **cái kia** đi.
- I don’t like the red **shoes**, but I like **the green ones**. ‖ Tôi không thích đôi giày đỏ, nhưng thích **đôi màu xanh lá**.
- Don’t buy those **apples**. Buy **the other ones**. ‖ Đừng mua mấy quả táo đó. Mua **mấy quả kia** đi.
- This **cup** is dirty. Can I have **a clean one**? ‖ Cái cốc này bẩn. Cho tôi **cái sạch** được không?
- That **biscuit** was nice. I’m going to have **another one**. ‖ Cái bánh quy đó ngon. Tôi sẽ ăn **thêm một cái**.
- These **cups** are dirty. Can we have **some clean ones**? ‖ Mấy cái cốc này bẩn. Cho chúng tôi **mấy cái sạch** được không?
- My **shoes** are very old. I’m going to buy **some new ones**. ‖ Giày của tôi cũ lắm rồi. Tôi sẽ mua **đôi mới**.
@rules
A: one = a/an + noun (I need a pen. Do you have one?). ‖ one = a/an + danh từ (I need a pen. Do you have one?).
B: one replaces a singular noun, ones a plural noun (which one / this one / which ones). ‖ one thay danh từ số ít, ones thay danh từ số nhiều (which one / this one / which ones).
C: the one … / the ones … + description (the one opposite the station). ‖ the one … / the ones … + phần mô tả (the one opposite the station).
D: the + adjective + one(s); a + adjective + one; some + adjective + ones; another one. ‖ the + tính từ + one(s); a + tính từ + one; some + tính từ + ones; another one.
