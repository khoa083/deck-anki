@rules
E109: Active → passive: keep the tense / modal and use be + past participle (must be paid, could have been sent, hasn’t been claimed); use by only when the agent is important. ‖ Chủ động → bị động: giữ thì / động từ khuyết thiếu và dùng be + quá khứ phân từ (must be paid, could have been sent, hasn’t been claimed); chỉ dùng by khi tác nhân quan trọng.
E110: Choose the passive tense from the time reference: has been done (since), is being done (now), was done / had been done (past), will be done / is going to be done (future), to be done (infinitive). ‖ Chọn thì bị động theo mốc thời gian: has been done (since), is being done (bây giờ), was done / had been done (quá khứ), will be done / is going to be done (tương lai), to be done (nguyên mẫu).
E111: get + past participle for things that happen (get lost, get cut off, get promoted); be (not get) for states and verbs like believe, respect, suppose. ‖ get + quá khứ phân từ cho sự việc xảy ra (get lost, get cut off, get promoted); dùng be (không dùng get) cho trạng thái và động từ như believe, respect, suppose.
E112: It is said that … → Subject + is said + to + infinitive / to be -ing / to have + past participle / to have been -ing. ‖ It is said that … → Chủ ngữ + is said + to + nguyên mẫu / to be -ing / to have + quá khứ phân từ / to have been -ing.
E113: Passive in narrative: was done (sequence), was being done (in progress), had been done (earlier), have been done (since then), will be done (future), to be done (infinitive). ‖ Bị động trong tường thuật: was done (trình tự), was being done (đang diễn ra), had been done (trước đó), have been done (từ đó đến nay), will be done (tương lai), to be done (nguyên mẫu).
E114: I’ll have it / them + past participle = I’ll arrange for someone to do it. ‖ I’ll have it / them + quá khứ phân từ = tôi sẽ thuê / nhờ người làm việc đó.
E115: have something done = arrange for somebody else to do something for you. ‖ have something done = nhờ / thuê người khác làm gì cho mình.
