@rules
E164: Adjectives describe nouns and follow be / seem / become / look; adverbs describe verbs, adjectives and past participles (efficiently organised, surprisingly good, absolutely fascinating); hard / near are adjectives and adverbs; lately = recently; good fun. ‖ Tính từ bổ nghĩa danh từ và đứng sau be / seem / become / look; trạng từ bổ nghĩa động từ, tính từ và quá khứ phân từ (efficiently organised, surprisingly good, absolutely fascinating); hard / near vừa là tính từ vừa là trạng từ; lately = gần đây; good fun.
E165: verb + adverb (shouted impatiently, tried hard); adverb + adjective (unnecessarily complicated, exceptionally demanding); well = in good health; well-paid. ‖ động từ + trạng từ (shouted impatiently, tried hard); trạng từ + tính từ (unnecessarily complicated, exceptionally demanding); well = khỏe; well-paid.
E166: the + superlative (the highest, the lowest); comparative + than (better than, worse than, higher … than, more than, less than); the same … as. ‖ the + so sánh nhất (the highest, the lowest); so sánh hơn + than (better than, worse than, higher … than, more than, less than); the same … as.
E167: not as much as; more than; the same amount as; the least. ‖ not as much as; more than; the same amount as; the least.
E168: -er / more … than; the -est / the most …; much + comparative; not as … as; as … as; any + comparative; irregular good / better / the best, bad / worse, far / further / furthest. ‖ -er / more … than; the -est / the most …; much + so sánh hơn; not as … as; as … as; any + so sánh hơn; bất quy tắc good / better / the best, bad / worse, far / further / furthest.
