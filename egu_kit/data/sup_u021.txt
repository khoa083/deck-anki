@rules
E132: + -ing: stop, admit, imagine, mind; + to …: ask, forget (= not remember to do), hope, afford; to be -ing (continuous infinitive), to be done (passive infinitive). ‖ + -ing: stop, admit, imagine, mind; + to …: ask, forget (= quên làm), hope, afford; to be -ing (nguyên mẫu tiếp diễn), to be done (nguyên mẫu bị động).
E133: + to …: decide, attempt (noun) to, appear, promise, manage, whether to; + -ing: postpone, avoid, deny (deny having done). ‖ + to …: decide, attempt (danh từ) to, appear, promise, manage, whether to; + -ing: postpone, avoid, deny (deny having done).
E134: + to …: hope, plan, fail, forget (to do), agree, offer; + -ing: suggest, finish, consider, risk, keep, avoid. ‖ + to …: hope, plan, fail, forget (to do), agree, offer; + -ing: suggest, finish, consider, risk, keep, avoid.
E135: want / order / ask somebody to do; regret doing; make somebody do; try to do (attempt); need doing (= need to be done); help somebody (to) do. ‖ want / order / ask ai đó to do; regret doing; make ai đó do; try to do (cố gắng); need doing (= cần được làm); help ai đó (to) do.
E136: advise somebody (not) to do; mind being done; threaten to do; claim to have done; keep doing; wonder whether to; go on doing; hate to do; forget to do; let somebody do; try to do (attempt) / try doing (experiment); would like to have done. ‖ advise ai đó (not) to do; mind being done; threaten to do; claim to have done; keep doing; wonder whether to; go on doing; hate to do; forget to do; let ai đó do; try to do (cố gắng) / try doing (thử); would like to have done.
