@title_vi: Cấu tạo câu bị động (2): động từ + -ing hoặc to-V
@theory
## A | Active verb + object + -ing → be + past participle + -ing | Chủ động động từ + tân ngữ + -ing → be + V3 + -ing
Verbs followed by **object + -ing** in the active are made passive with ‘**be**’ + **past participle** + **-ing**: ‖ Động từ có **tân ngữ + V-ing** ở chủ động chuyển sang bị động bằng ‘**be**’ + **V3** + **V-ing**:
- They **saw** the monkey **climbing** over the fence. (= active) → The monkey **was seen climbing** over the fence. (= passive) ‖ Họ thấy con khỉ đang trèo qua hàng rào. → Con khỉ **bị nhìn thấy đang trèo** qua hàng rào.
Also: **bring**, **catch**, **hear**, **find**, **keep**, **notice**, **observe**, **send**, **show** ‖ Tương tự: **bring**, **catch**, **hear**, **find**, **keep**, **notice**, **observe**, **send**, **show**
## B | Verb + being + past participle | Động từ + being + V3
Some verbs that can be followed by an **-ing** form can be used with a passive form **being** + **past participle**: ‖ Một số động từ đi với **V-ing** có thể dùng với dạng bị động **being** + **V3**:
- I really **love being given** presents. ‖ Tôi rất thích **được tặng** quà.
- The children **enjoyed being taken** to the zoo. ‖ Bọn trẻ thích thú khi **được đưa** đi sở thú.
Also: **avoid**, **deny**, **describe**, **dislike**, **face**, **hate**, (**not**) **imagine**, **like**, **remember**, **report**, **resent** ‖ Tương tự: **avoid**, **deny**, **describe**, **dislike**, **face**, **hate**, (**not**) **imagine**, **like**, **remember**, **report**, **resent**
## C | Noun phrase + -ing clause: usually no passive | Cụm danh từ + mệnh đề -ing: thường không có bị động
Verbs which in the active are followed by an object consisting of a noun phrase and **-ing** clause usually have no passive: ‖ Động từ có tân ngữ gồm cụm danh từ và mệnh đề **-ing** ở chủ động thường không có dạng bị động:
- I dread **him** (*or* **his**) **finding out**. (*but not* He is dreaded finding out) ‖ Tôi sợ **anh ấy phát hiện ra**.
Also: **anticipate**, **appreciate**, **dislike**, **forget**, **hate**, **imagine**, **like**, (**not**) **mind**, **recall**, **remember** ‖ Tương tự: **anticipate**, **appreciate**, **dislike**, **forget**, **hate**, **imagine**, **like**, (**not**) **mind**, **recall**, **remember**
## D | Verb + object + to-infinitive → be + past participle + to-infinitive | Động từ + tân ngữ + to-V → be + V3 + to-V
The active pattern **verb + object + to-infinitive** is made passive with ‘**be**’ + **past participle** + **to-infinitive**. Compare: ‖ Mẫu chủ động **động từ + tân ngữ + to-V** chuyển sang bị động bằng ‘**be**’ + **V3** + **to-V**. So sánh:
- Mr Wang **has taught** Peter **to sing** for years. → Peter **has been taught to sing** (by Mr Wang) for years. ‖ Thầy Wang dạy Peter hát nhiều năm rồi. → Peter **được dạy hát** (bởi thầy Wang) nhiều năm rồi.
Also: **advise**, **allow**, **ask**, **believe**, **consider**, **expect**, **feel**, **instruct**, **mean**, **order**, **require**, **tell**, **understand** ‖ Tương tự: **advise**, **allow**, **ask**, **believe**, **consider**, **expect**, **feel**, **instruct**, **mean**, **order**, **require**, **tell**, **understand**
Note that in some contexts it is possible to make both verbs passive: ‖ Lưu ý: trong một số ngữ cảnh có thể chuyển cả hai động từ sang bị động:
- Changes to the taxation system **are expected to be proposed**. (compare the active We **expect** the government **to propose** changes to the taxation system.) ‖ Những thay đổi trong hệ thống thuế **được dự kiến sẽ được đề xuất**.
Some verbs followed by an **object + to-infinitive** in the active have no passive: ‖ Một số động từ có **tân ngữ + to-V** ở chủ động không có bị động:
- Susan **liked Karl to be** there. (*but not* Karl was liked to be there.) ‖ Susan **muốn Karl có mặt** ở đó.
Also: (**can’t**) **bear**, **hate**, **love**, **need**, **prefer**, **want**, **wish** (= ‘liking’ and ‘wanting’ verbs) ‖ Tương tự: (**can’t**) **bear**, **hate**, **love**, **need**, **prefer**, **want**, **wish** (= động từ ‘thích’ và ‘muốn’)
## E | Verb + to-infinitive + object → verb + to be + past participle | Động từ + to-V + tân ngữ → động từ + to be + V3
The active pattern **verb + to-infinitive + object** is made passive with **verb + to be + past participle**. Compare: ‖ Mẫu chủ động **động từ + to-V + tân ngữ** chuyển sang bị động bằng **động từ + to be + V3**. So sánh:
- Supermarkets **started to sell** fresh pasta only in the 1990s. → Fresh pasta **started to be sold** by supermarkets only in the 1990s. ‖ Siêu thị mới bắt đầu bán mì Ý tươi từ những năm 1990. → Mì Ý tươi mới **bắt đầu được bán** ở siêu thị từ những năm 1990.
Also: (i) **appear**, **begin**, **come**, **continue**, **seem**, **tend**; (ii) **agree**, **aim**, **arrange**, **attempt**, **hope**, **refuse**, **want** ‖ Tương tự: (i) **appear**, **begin**, **come**, **continue**, **seem**, **tend**; (ii) **agree**, **aim**, **arrange**, **attempt**, **hope**, **refuse**, **want**
The verbs in group (i) (and **start**) have corresponding meanings in active and passive sentences, but the verbs in group (ii) do not. Compare: ‖ Các động từ nhóm (i) (và **start**) có nghĩa tương ứng ở câu chủ động và bị động, còn nhóm (ii) thì không. So sánh:
- People have come to see organic food as something only the wealthy eat. (active) corresponds to Organic food **has come to be seen** as something only the wealthy eat. (passive) ‖ Người ta dần coi thực phẩm hữu cơ là thứ chỉ người giàu ăn. tương ứng với Thực phẩm hữu cơ **dần bị coi** là thứ chỉ người giàu ăn.
- Petra wanted to help me. (active) does not correspond to I **wanted to be helped** by Petra. (passive) ‖ Petra muốn giúp tôi. không tương ứng với Tôi **muốn được** Petra **giúp**.
@rules
A: see / hear / catch / find / keep / send + object + -ing → be seen / caught / found / kept … + -ing. ‖ see / hear / catch / find / keep / send + tân ngữ + V-ing → be seen / caught / found / kept … + V-ing.
B: avoid / deny / enjoy / hate / love / remember / resent / face + being + past participle. ‖ avoid / deny / enjoy / hate / love / remember / resent / face + being + V3.
C: dread / appreciate / mind / remember + noun phrase + -ing → usually no passive. ‖ dread / appreciate / mind / remember + cụm danh từ + V-ing → thường không có bị động.
D: advise / ask / expect / require / tell + object + to-infinitive → be + past participle + to-infinitive; like / want / prefer + object + to-infinitive → no passive. ‖ advise / ask / expect / require / tell + tân ngữ + to-V → be + V3 + to-V; like / want / prefer + tân ngữ + to-V → không có bị động.
E: start / begin / come / continue / seem + to be + past participle (same meaning); agree / arrange / hope / want + to be + past participle (different meaning). ‖ start / begin / come / continue / seem + to be + V3 (nghĩa tương ứng); agree / arrange / hope / want + to be + V3 (nghĩa khác).
