E184: Phrasal verb + preposition: look forward to, run away from, fall out with, get on with, cut down on, go up to, point out to, come up with, get back to, get away with. ‖ Cụm động từ + giới từ: look forward to, run away from, fall out with, get on with, cut down on, go up to, point out to, come up with, get back to, get away with.
E185: get away = go on holiday; get back = return; get in = enter; get on = progress / board a bus; get by = manage with little money. ‖ get away = đi nghỉ; get back = quay về; get in = vào; get on = tiến triển / lên xe; get by = xoay xở (với ít tiền).
E186: take away = remove; be taken in = be deceived; take down = remove from a wall / window; take up = start a hobby / fill space; take off = remove clothes / leave the ground. ‖ take away = mang đi; be taken in = bị lừa; take down = gỡ xuống; take up = bắt đầu một sở thích / chiếm chỗ; take off = cởi ra / cất cánh.
E187: go in = enter; go on = happen / continue; go back = return; go away = leave home for a period; go out = stop shining / leave the house. ‖ go in = đi vào; go on = xảy ra / tiếp tục; go back = quay về; go away = đi xa một thời gian; go out = tắt / ra ngoài.
E188: put out = extinguish; put on = dress / start equipment / music; put back = return to its place; put off = postpone; put down = place on the ground. ‖ put out = dập tắt; put on = mặc / bật thiết bị / nhạc; put back = đặt lại chỗ cũ; put off = hoãn; put down = đặt xuống.
E189: turn on / off = start / stop a machine; turn out = be found to be; turn up = arrive / increase volume; turn down = reduce volume. ‖ turn on / off = bật / tắt máy; turn out = hóa ra; turn up = xuất hiện / tăng âm lượng; turn down = giảm âm lượng.
E190: Pronoun objects go between verb and particle (fill it in, tear it up, hand it back, cross it out, rub it out); noun objects can go before or after the particle; be held up = be delayed. ‖ Tân ngữ là đại từ đứng giữa động từ và tiểu từ (fill it in, tear it up, hand it back, cross it out, rub it out); tân ngữ là danh từ đứng trước hoặc sau tiểu từ; be held up = bị chậm trễ.
E191: find out, break down (of a relationship), put up with, show off, let somebody down, bring up a child, keep somebody away from, fall out with, run away from. ‖ find out, break down (mối quan hệ đổ vỡ), put up with, show off, let somebody down, bring up a child, keep somebody away from, fall out with, run away from.
