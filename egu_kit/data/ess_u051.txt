@title_vi: work/working / go/going / do/doing (nguyên mẫu, to + nguyên mẫu, -ing)
@theory
## A | work / go / be etc. (infinitive) | work / go / be v.v. (nguyên mẫu)
**will / can / must** etc. + infinitive: ‖ **will / can / must** v.v. + nguyên mẫu:
|! | example ‖ ví dụ
| **will / shall** (→ Units 27–28) | Anna **will be** here soon. / **Shall** I **open** the window?
| **might / may** (→ Unit 29) | I **might phone** you later. / **May** I **sit** here?
| **can / could** (→ Unit 30) | I **can’t meet** you tomorrow. / **Could** you **pass** the salt, please?
| **must** (→ Unit 31) | It’s late. I **must go** now.
| **should** (→ Unit 32) | You **shouldn’t work** so hard.
| **would** (→ Unit 34) | **Would** you **like** some coffee?
**do / does / did** + infinitive: ‖ **do / does / did** + nguyên mẫu:
|! | example ‖ ví dụ
| **do / does** (present simple → Units 6–7) | **Do** you **work**? / They **don’t work** very hard. / Helen **doesn’t know** many people. / How much **does** it **cost**?
| **did** (past simple → Unit 12) | What time **did** the train **leave**? / We **didn’t sleep** well.
## B | to work / to go / to be etc. (to + infinitive) | to work / to go / to be v.v. (to + nguyên mẫu)
|! | example ‖ ví dụ
| (I’m) **going to** … (→ Unit 26) | I**’m going to play** tennis tomorrow. / What **are** you **going to do**?
| (I) **have to** … (→ Unit 33) | I **have to go** now. / Everybody **has to eat**.
| (I) **want to** … (→ Unit 52) | Do you **want to go** out? / They don’t **want to come** with us.
| (I) **would like to** … (→ Unit 34) | I**’d like to talk** to you. / **Would** you **like to go** out?
| (I) **used to** … (→ Unit 36) | Dave **used to work** in a factory.
## C | working / going / playing etc. | working / going / playing v.v.
|! | example ‖ ví dụ
| **am / is / are + -ing** (present continuous → Units 3–4, 8, 25) | Please be quiet. I**’m working**. / Tom **isn’t working** today. / What time **are** you **going** out?
| **was / were + -ing** (past continuous → Units 13–14) | It **was raining**, so we didn’t go out. / What **were** you **doing** at 11.30 yesterday?
@rules
A: will/shall/might/may/can/could/must/should/would and do/does/did + infinitive (without to). ‖ will/shall/might/may/can/could/must/should/would và do/does/did + nguyên mẫu (không to).
B: going to / have to / want to / would like to / used to + infinitive (to + infinitive). ‖ going to / have to / want to / would like to / used to + nguyên mẫu (to + nguyên mẫu).
C: am/is/are/was/were + -ing (continuous tenses). ‖ am/is/are/was/were + -ing (các thì tiếp diễn).
