@rules
E155: all / none / one of them; both (of) the men; neither of the men + singular verb (was). ‖ all / none / one of them; both (of) the men; neither of the men + động từ số ít (was).
E157: all / most / few + noun (in general); none / any / half / each of + the / my / them (specific); much + uncountable; each + singular noun. ‖ all / most / few + danh từ (nói chung); none / any / half / each of + the / my / them (cụ thể); much + không đếm được; each + danh từ số ít.
E158: all of + the / them; none (pronoun) / no + noun; anybody + singular verb; few (= not many) vs a few (= some); all the information (not the whole + uncountable); any (= it doesn’t matter which); so much + uncountable; everybody knows; half of it. ‖ all of + the / them; none (đại từ) / no + danh từ; anybody + động từ số ít; few (= không nhiều) khác a few (= một vài); all the information (không dùng the whole + không đếm được); any (= cái nào cũng được); so much + không đếm được; everybody knows; half of it.
E159: hardly anything; all the + plural; both / most (of) the; none of the + noun; all of them; every + singular; neither of the + singular verb; somebody / somewhere (particular), anywhere (no matter where); little (= not much) / a few (= some); no + noun; the whole + singular countable; no more … than. ‖ hardly anything; all the + số nhiều; both / most (of) the; none of the + danh từ; all of them; every + số ít; neither of the + động từ số ít; somebody / somewhere (cụ thể), anywhere (bất cứ đâu); little (= không nhiều) / a few (= một vài); no + danh từ; the whole + danh từ đếm được số ít; no more … than.

E157 | I’ll have to buy a new tie. ___ the ones I’ve got matches this jacket. | None of | No | Few | Tôi phải mua cà vạt mới. [Không chiếc nào] tôi có hợp với áo khoác này. | none of the + danh từ.
