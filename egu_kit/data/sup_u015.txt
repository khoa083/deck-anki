@rules
E94: if + past → would + base form (imaginary present / future); if + past perfect → would have + past participle (imaginary past). ‖ if + quá khứ → would + nguyên mẫu (tưởng tượng ở hiện tại / tương lai); if + quá khứ hoàn thành → would have + quá khứ phân từ (tưởng tượng về quá khứ).
E95: if + had + past participle → would have + past participle (past); if + past → would + base form (present). ‖ if + had + quá khứ phân từ → would have + quá khứ phân từ (quá khứ); if + quá khứ → would + nguyên mẫu (hiện tại).
E96: Imagining a different past: If + had (not) + past participle, … would (not) have + past participle. ‖ Tưởng tượng quá khứ khác đi: If + had (not) + quá khứ phân từ, … would (not) have + quá khứ phân từ.
E97: A past condition with a present result: If + past perfect, … would / could + base form (now). ‖ Điều kiện trong quá khứ, kết quả ở hiện tại: If + quá khứ hoàn thành, … would / could + nguyên mẫu (bây giờ).
E99: Real future → if + present, will; imaginary present → if + past, would / could; imaginary past → if + past perfect, would have + past participle. ‖ Tương lai có thật → if + hiện tại, will; hiện tại tưởng tượng → if + quá khứ, would / could; quá khứ tưởng tượng → if + quá khứ hoàn thành, would have + quá khứ phân từ.
E100: I wish + past (I wish I had / worked / lived / didn’t …, I wish I were / was …, I wish I could …) for present situations. ‖ I wish + quá khứ (I wish I had / worked / lived / didn’t …, I wish I were / was …, I wish I could …) cho tình huống hiện tại.
E101: I wish somebody would / wouldn’t do something = I want them to change behaviour that annoys me. ‖ I wish ai đó would / wouldn’t làm gì = tôi muốn họ thay đổi hành vi gây khó chịu.
E102: I wish + past for the present (I wish I had / knew); I wish + past perfect for regrets about the past (I wish I’d learned, they hadn’t moved, they’d never started). ‖ I wish + quá khứ cho hiện tại (I wish I had / knew); I wish + quá khứ hoàn thành cho hối tiếc về quá khứ (I wish I’d learned, they hadn’t moved, they’d never started).
