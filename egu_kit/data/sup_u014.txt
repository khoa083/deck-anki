@rules
E88: if / when + present for the future (not will); will in the main clause for real possibilities; if + past → would (not did) for imaginary situations. ‖ if / when + hiện tại cho tương lai (không dùng will); will ở mệnh đề chính cho khả năng có thật; if + quá khứ → would (không dùng did) cho tình huống tưởng tượng.
E89: will … if + present (real possibility); would … if + past (imaginary or unlikely). ‖ will … if + hiện tại (khả năng có thật); would … if + quá khứ (tưởng tượng hoặc khó xảy ra).
E90: if + past → would + base form; if + present → will / may + base form; if I / he / she was or were; could = would be able to. ‖ if + quá khứ → would + nguyên mẫu; if + hiện tại → will / may + nguyên mẫu; if I / he / she was hoặc were; could = would be able to.
E91: Imaginary situations: if + past, would (’d) + base form; real possibilities: if + present, will + base form. ‖ Tình huống tưởng tượng: if + quá khứ, would (’d) + nguyên mẫu; khả năng có thật: if + hiện tại, will + nguyên mẫu.
